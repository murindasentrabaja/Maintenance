⚙️ Sambungkan ke Apps Script dulu

File ini belum tersambung ke backend Google Apps Script. Ikuti langkah berikut agar data sinkron dengan spreadsheet Maintenance:

  1. Buka spreadsheet Maintenance Anda → Extensions → Apps Script.
  2. Tempel isi file Code.gs yang sudah disediakan.
  3. Klik Deploy → New deployment → tipe Web app, akses Anyone.
  4. Salin URL Web App hasil deploy.
  5. Buka file index.html ini, cari baris SCRIPT_URL: di bagian atas <script>, lalu tempel URL Anda di sana.
  6. Simpan & muat ulang halaman ini.

Detail lengkap ada di pesan yang menyertai file ini.
